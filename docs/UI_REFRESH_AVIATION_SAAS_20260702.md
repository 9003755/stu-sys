# 学员培训报名系统 UI 改造说明

日期：2026-07-02

## 目标

本次改造目标是将现有学员培训报名系统的界面从“临时拼装感、风格不统一”提升为“现代、简洁、专业、可信的航空蓝 SaaS 后台风格”。

核心约束：

- 不修改业务流程。
- 不修改表单字段。
- 不修改 Supabase 查询、写入、删除、导出、审核、上传等业务逻辑。
- 不修改路由结构和权限结构。
- 只调整 UI 表现层，包括颜色、间距、卡片、表格、按钮、输入框、弹窗、页面外壳和响应式表现。

## 设计方向

### 风格定位

采用航空蓝 SaaS 后台风格：

- 主色：稳重蓝，强调专业、可信、航空行业属性。
- 背景：浅灰蓝，减少页面压迫感。
- 卡片：白底、细边框、轻阴影。
- 表格：低噪声、信息密度适中、操作区清晰。
- 表单：统一输入框高度、圆角、focus 状态和错误状态。
- 按钮：主操作使用航空蓝，危险操作使用红色，次要操作弱化。

### 设计原则

- 用统一设计变量替代散乱颜色。
- 用卡片和边框建立层级，避免厚重阴影。
- 保留原页面的信息架构和业务功能。
- 优先保证高频场景：登录、报名填写、资料上传、管理员审核、班级管理。
- 后台页面更偏 SaaS 管理系统，学生端更偏清晰、安全、移动端友好。

## 主要实现方法

### 1. 全局设计变量

在 `src/index.css` 中新增并统一了 UI token：

- `--ui-primary`
- `--ui-primary-hover`
- `--ui-primary-soft`
- `--ui-page`
- `--ui-card`
- `--ui-surface`
- `--ui-border`
- `--ui-title`
- `--ui-text`
- `--ui-muted`
- `--ui-success`
- `--ui-warning`
- `--ui-danger`
- `--ui-radius-*`
- `--ui-shadow-*`

同时将原有 `--vercel-*` 变量映射到新的航空蓝视觉体系，降低对已有页面代码的侵入。

### 2. 全局组件视觉覆盖

由于项目中大量页面直接使用 Tailwind class，且部分文件存在历史中文编码问题，本次采用两种方式结合：

- 对结构清晰、编码正常的页面，直接调整 JSX class。
- 对历史编码不稳定、业务代码较多的页面，优先通过 `src/index.css` 做视觉覆盖，避免误伤业务逻辑。

覆盖内容包括：

- 按钮颜色、圆角、hover。
- 输入框边框、focus ring、placeholder。
- 表格表头、行 hover、分割线。
- 卡片边框、圆角、阴影。
- 弹窗背景、阴影、遮罩。
- 超级管理员旧黑色控制台风格向浅色后台风格转换。

### 3. 页面入口统一

以下入口页统一为浅色航空蓝登录/注册风格：

- 学员/管理员登录页。
- 学员注册页。
- 管理员注册页。
- 超级管理员登录页。
- 报名确认页中的登录/注册和成功状态。

统一点：

- 白色登录卡片。
- 顶部航空蓝渐变线。
- 蓝色主按钮。
- 统一输入框高度和圆角。
- 保留原认证、注册、OTP、跳转逻辑。

### 4. 学生端报名/档案页

`StudentProfile.jsx` 保留原上传、压缩、草稿恢复、提交、报名逻辑，仅调整：

- 分组标题样式。
- 表单控件样式。
- 上传区域样式。
- 页面卡片圆角和边框。
- 底部提交按钮。
- 页面背景和内容容器。

### 5. 管理员后台

`AdminDashboard.jsx` 重做了页面外壳：

- 白色 SaaS 顶栏。
- 品牌标识。
- 当前管理员信息块。
- 班级管理 / 学员列表 Tab。
- 退出按钮弱化为危险 hover 状态。

保留：

- 管理员校验逻辑。
- Tab 状态。
- `ClassManagement` 和 `EnrollmentManagement` 子组件调用。
- 所有班级、学员、导出、删除、审核等业务逻辑。

### 6. 超级管理员页面

超级管理员相关页面原本偏黑色控制台风格。本次通过全局 CSS 覆盖，使其更接近统一浅色后台：

- 页面背景改为浅灰蓝。
- 表格和弹窗改为白色卡片。
- 表头、边框、文字、状态标签统一。
- 保留原超级管理员功能和权限逻辑。

- 静态 Demo 页面仅作为视觉方向参考，不代表真实业务页面。
